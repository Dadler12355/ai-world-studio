# AI World Studio

A human-directed AI production studio for playable Unity worlds, cinematic storytelling, and interactive characters.

## Team
- **Human director:** vision, playtesting and approvals
- **ChatGPT:** creative producer, briefs, planning and QA
- **Claude Code:** Unity implementation, tooling and testing
- **Higgsfield:** visual references, cinematics and supported 3D generation
- **Blender:** mesh cleanup and asset export
- **ElevenLabs:** voices and sound
- **n8n (later):** orchestration, approvals and job tracking
- **GitHub:** shared project history and documentation
